## 1. Create the special profile repository

1. Open https://github.com/new
2. Set the repository name to exactly `vo1dfull`.
3. Make it **Public**.
4. Add a README if GitHub offers the checkbox.
5. Create the repository.

The repository name must exactly match your username for GitHub to show its README on your profile.

## 2. Add the profile README

1. Open the `vo1dfull/vo1dfull` repository.
2. Replace its `README.md` with the `README.md` in this package.
3. Commit the changes.
4. Open https://github.com/vo1dfull to preview it.

## 3. Enable the contribution snake (optional)

1. Copy `.github/workflows/snake.yml` into the same path in the profile repository.
2. Commit and push it.
3. In the repository, open **Settings → Actions → General**.
4. Under **Workflow permissions**, ensure workflows can write to the repository if your organization/account policy requires that setting.
5. Open **Actions → Generate contribution snake → Run workflow**.
6. After it succeeds, the workflow creates/updates the `output` branch.
7. Add this image inside the README wherever you want the snake to appear:

   `![Contribution snake](https://raw.githubusercontent.com/vo1dfull/vo1dfull/output/github-snake-dark.svg)`
