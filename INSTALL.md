# vo1dfull profile README refresh

This package replaces the previous river/snake version with a cleaner profile built around your workstation image.

## Install

1. Extract the ZIP.
2. Open your public `vo1dfull/vo1dfull` profile repository.
3. Replace `README.md` with the included `README.md`.
4. Upload the included `assets/` folder (including `workstation.png` and `pixel-companion.svg`).
5. Commit the changes to `main`.

## What changed

- Uses the latest workstation image you uploaded as the central image.
- Restores a cohesive technology icon row via Skill Icons.
- Removes the broken custom commit river and contribution snake from the README.
- Adds a GitHub stats card, top-languages card, and activity graph.
- Adds a small custom pixel desk companion.
- Keeps the Rust and cybersecurity project areas as clearly labelled works in progress rather than inventing repository names.

## External image services

The tech icons use `skillicons.dev`; the stats cards use `ghstats.dev`; the activity graph uses the current Cloudflare Workers deployment documented by its project. These are third-party image services, so their availability is outside your repository's control.
